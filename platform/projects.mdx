A project is the primary organisational unit inside the Uncertainty Engine. Every workflow you build and every resource you upload lives inside a project, so your team always has a single, well-scoped place to collaborate. Projects also act as the namespace for API calls — whenever you run a workflow or fetch a resource you supply the project ID alongside the resource identifier.

## What a project contains

Each project holds:

- **Workflows** — saved node graphs that team members can run, version, and share.
- **Resources** — uploaded files such as datasets and model artefacts that workflows reference.
- **Members** — all users who belong to your organisation can access shared projects, so there is no extra permission step beyond having a valid account.

<Note>
  Project IDs appear in every workflow and resource API call. Copy the ID from
  the web UI project settings page or retrieve it programmatically with the SDK
  as shown below.
</Note>

## List your projects

After authenticating, call `client.projects.list()` to fetch every project your organisation owns.

```python
from uncertainty_engine import Client

client = Client()
client.authenticate()

projects = client.projects.list()
for project in projects:
    print(project.id, project.name)
```

The call returns a list of project objects. Each object exposes at minimum `id` and `name`. Save the `id` value — you will need it whenever you run a workflow or interact with resources inside that project.

## Create a project

Pass a name string to `client.projects.create()` to create a new project. The platform returns the new project object, including the generated project ID.

```python
from uncertainty_engine import Client

client = Client()
client.authenticate()

project = client.projects.create(name="My Uncertainty Study")
print("Created project:", project.id)
```

<Tip>
  Choose a descriptive name that reflects the domain or experiment — for
  example, `"Sensor Calibration — Q3"`. Clear names make it easier for
  teammates to find the right project in the web UI.
</Tip>

## Delete a project

Remove a project and all its contents with `client.projects.delete()`. Pass the project ID you want to remove.

```python
client.projects.delete(project_id="your_project_id")
```

<Warning>
  Deleting a project is permanent. All workflows and resources inside the
  project are also deleted and cannot be recovered. Double-check the project ID
  before calling `delete`.
</Warning>

## Use project IDs in other calls

Once you have a project ID, reference it in workflow and resource operations:

```python
# Run a workflow inside a project
result = client.run_workflow(
    project_id="your_project_id",
    workflow_id="your_workflow_id",
    inputs=[],
)

# List resources stored in a project
resources = client.resources.list(project_id="your_project_id")
```

See [Workflows](/platform/workflows) and [Resources](/platform/resources) for full details on these operations.
