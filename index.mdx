Build AI workflows using a visual node editor or the Python SDK, train probabilistic machine learning models, and deploy results you can trust — with quantified uncertainty at every step.

## What You Can Build

The Uncertainty Engine lets you compose AI workflows from a library of purpose-built nodes — each one a discrete operation that runs on the platform's infrastructure. Connect nodes together to form graphs, save them as reusable workflows, and execute them on demand from the web UI or via the Python SDK.

## Get Started

<Steps>
  <Step title="Create an account">
    Request access at [digilab.ai](https://www.digilab.ai) and set up your Uncertainty Engine account.
  </Step>
  <Step title="Install the Python SDK">
    ```bash
    pip install uncertainty-engine
    ```
  </Step>
  <Step title="Authenticate">
    ```bash
    export UE_USERNAME="your@email.com"
    export UE_PASSWORD="your_password"
    ```
  </Step>
  <Step title="Run your first node">
    ```python
    from uncertainty_engine import Client
    from uncertainty_engine.nodes.basic import Add

    client = Client()
    client.authenticate()

    result = client.run_node(Add(lhs=1, rhs=2))
    print(result.outputs)  # {'ans': 3.0}
    ```
  </Step>
</Steps>

<Tip>
  The Uncertainty Engine is currently in beta. Features and APIs are evolving rapidly. Pin your SDK version in production and watch the [changelog](/changelog) for updates.
</Tip>
