The fastest way to experience the Uncertainty Engine is through its Python SDK. This guide walks you from a fresh Python environment to a running computation in five steps. By the end you will have authenticated against the platform, executed a node, and seen how to discover the full node library — the foundation for everything else you will build.

<Tip>
  The Uncertainty Engine is currently in **beta**. We recommend pinning your SDK version (e.g. `uncertainty-engine==0.14.1`) in `requirements.txt` or `pyproject.toml` so that API changes between releases don't break your workflows unexpectedly.
</Tip>

<Steps>
  <Step title="Request access">
    The Uncertainty Engine is available to approved organisations. If you don't yet have an account, visit [digilab.ai](https://digilab.ai) to request access. Once approved, you will receive a username and temporary password by email.

    If your organisation is already on the platform, ask your administrator to invite you — new users are provisioned through the web UI.
  </Step>

  <Step title="Install the SDK">
    The SDK requires **Python 3.10 or later**. Install it from PyPI using your preferred package manager:

    <CodeGroup>
      ```bash pip
      pip install uncertainty-engine
      ```

      ```bash poetry
      poetry add uncertainty-engine
      ```
    </CodeGroup>

    The base package is intentionally lightweight. If you need additional capabilities, install the relevant extras:

    | Extra | Installs | Use case |
    |---|---|---|
    | `data` | numpy, pandas | Working with array and tabular data |
    | `notebook` | ipykernel | Running SDK code in Jupyter notebooks |
    | `vis` | matplotlib, networkx | Visualising graphs and results |

    ```bash
    # Example: install with data and visualisation support
    pip install "uncertainty-engine[data,vis]"
    ```
  </Step>

  <Step title="Set your credentials">
    The SDK reads your credentials from two environment variables. Set them in your shell before running any Python code:

    ```bash
    export UE_USERNAME="your@email.com"
    export UE_PASSWORD="your-password"
    ```

    For persistent configuration, add these lines to your shell profile (e.g. `~/.bashrc` or `~/.zshrc`), or use a `.env` file with a library like [`python-dotenv`](https://pypi.org/project/python-dotenv/).

    <Warning>
      Never commit credentials to source control. Use environment variables, a secrets manager, or a `.env` file that is listed in `.gitignore`.
    </Warning>

    After your first successful `authenticate()` call, the SDK caches your auth token in a `.ue_auth` file in your home directory so you don't need to re-authenticate on every run.
  </Step>

  <Step title="Authenticate and run your first node">
    With your credentials in place, you can authenticate and run a node in a few lines of Python. The example below uses the `Add` node from `nodes.basic` — the simplest way to verify the SDK is working end-to-end:

    ```python
    from uncertainty_engine import Client
    from uncertainty_engine.nodes.basic import Add

    # Create a client (connects to the production environment by default)
    client = Client()

    # Exchange your credentials for an auth token
    client.authenticate()

    # Run a single node synchronously
    result = client.run_node(Add(lhs=1, rhs=2))

    print(result.outputs)  # {'ans': 3.0}
    ```

    `run_node` is a synchronous helper — it submits the node, polls until the job completes, and returns the result. For long-running computations you can use `queue_node` instead, which returns a `Job` immediately so you can check its status later.

    <Note>
      Every node execution consumes tokens from your organisation's quota. The `Add` node used above costs very few tokens, but more complex nodes and large workflows consume proportionally more. Check your available balance with `client.view_tokens()`.
    </Note>
  </Step>

  <Step title="List available nodes">
    The platform has a growing library of nodes across multiple categories. To see what's available, call `list_nodes` with an optional category filter:

    ```python
    # List all nodes in the basic category
    nodes = client.list_nodes(category="basic")
    print(nodes)

    # List all nodes across every category
    all_nodes = client.list_nodes()
    print(all_nodes)
    ```

    To get detailed information about a specific node — including its input/output schema and available versions — use `get_node_info`:

    ```python
    info = client.get_node_info(node="Add")
    print(info)
    ```

    You can also search the library by keyword using `query_nodes`:

    ```python
    results = client.query_nodes(queries=["gaussian process", "regression"])
    print(results)
    ```
  </Step>
</Steps>
